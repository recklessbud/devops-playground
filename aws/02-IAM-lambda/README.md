# 02- IAM AWS LAMBDA, S3, & API-GATEWAY

A hands on project where I built a lambda fuction, added an API gateway and attach an S3 bucket to it. 

## What I did
- I first created the s3 bucket and uploaded some files to it.
- Created a policies for the bucket to be to be attached to roles to be the assumed by the lambda [polices](polices.txt)
- Created the lambda and attached the a role to be assumed
- Added an API Gateway trigger to invoke the function
